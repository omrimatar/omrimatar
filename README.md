## איך לקרוא את הטבלה

| עמודה | משמעות |
|-------|---------|
| `מספר` | מספר רץ של המשחק (1–72 שלב הבתים, 73–104 נוקאאוט) |
| `תאריך` | תאריך המשחק |
| `שלב` | בתים / שלב 32 / שמינית גמר / רבע גמר / חצי גמר / מקום שלישי / גמר |
| `בית` | אות הבית (A–L) בשלב הבתים |
| `מארחת` / `אורחת` | הקבוצות (הקבוצה הראשונה ברשימה הרשמית = "מארחת") |
| `סטטוס` | `שוחק` = המשחק כבר הסתיים · `עתידי` = טרם שוחק |
| `תוצאת_אמת` | התוצאה האמיתית של משחקים שהסתיימו (אחרת `—`) |
| `תוצאה_סבירה_חיזוי` | התוצאה הסבירה ביותר שחזינו למשחקים עתידיים (אחרת `—`) |
| `מועמדת_מועדפת` | הקבוצה המועדפת לניצחון לפי שוק ההימורים (או `תיקו`) |
| `הערה` | למשחקים שהסתיימו: **"אין הימור"**. למשחקים עתידיים: בסיס החיזוי |

הפורמט של התוצאה הוא `מארחת-אורחת` (למשל `2-1` = 2 למארחת, 1 לאורחת).

## שיטת החיזוי למשחקים עתידיים

מאחר שיחסי ההימור ל**תוצאה מדויקת** (correct score) משתנים כל הזמן ואין דרך מעשית למשוך אותם בזמן אמת ל-66 משחקי הבתים העתידיים, החיזוי מבוסס על:

1. **המועמדת המועדפת בשוק ההימורים** (יחסי 1X2 / מנצחת הבית / זוכת הטורניר) — קביעת מי הפייבוריטית בכל משחק.
2. **פער העוצמה בין הקבוצות** + **יתרון בית** למארחות (מקסיקו, קנדה, ארה"ב) — לבחירת התוצאה הסבירה ביותר.
3. נטייה לתוצאות נמוכות-בינוניות אופייניות למונדיאל (1-0, 2-0, 2-1, 1-1).

לפי שוק ההימורים נכון להיום, **המועמדות המובילות לאליפות**: ספרד (450+), צרפת (500+), אנגליה (700+), ברזיל (800+), פורטוגל וארגנטינה (900+), גרמניה (1400+), הולנד (2000+).

### הערכה מתוקפת (Validated estimate)

מאחר שחיזוי הניקוד הרגיל הוא המרה היוריסטית מ"מי הפייבוריט" ל"באיזה ניקוד", הוספנו **הערכה שנייה הנשענת ישירות על שוק התוצאה המדויקת (Correct Score)** — התוצאה בעלת ההסתברות הגבוהה ביותר לפי מודל/שוק ההימורים (מקור: Forebet). זמינה למחזור המשחקים הראשון בכל בית (20 משחקים, 13–17.6), שעבורם השוק כבר פעיל. בקובץ ה-CSV: עמודות `הערכה_מתוקפת` ו-`מקור_תיקוף`; באתר: שורת "✔ הערכה מתוקפת" מתחת לניקוד החזוי.
